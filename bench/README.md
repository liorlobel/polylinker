# polylinker-bench

A public truth set for plasmid operations. **CC0-1.0** — no attribution
required, no strings. Run it against anything.

## Why

Every plasmid editor claims to compute restriction sites correctly. There is no
shared way to check. The failures that matter are silent: a site that spans the
origin of a circular molecule and gets missed, an isoschizomer cutting in the
wrong place, a correct assembly product rejected because it came back rotated.
None of these look like errors — they look like answers.

This is a set of cases with known-correct expected values, in a format any tool
can consume.

## The rule that makes it worth anything

**No expected value in this set is produced by Polylinker.** Each comes from an
independent tool:

| operation | oracle |
|---|---|
| `identity` | [`seguid`](https://github.com/seguid/seguid-python) 0.2.1 — the SEGUID v2 reference |
| `digest` | Biopython 1.87, `Bio.Restriction` |
| `pcr` | pydna 5.5.16 |
| `assembly` | pydna 5.5.16 |

A benchmark generated by the tool it grades measures nothing. Where Polylinker
and the oracle disagree, the oracle is right and Polylinker fails.

Every sequence is synthetic, which is what lets the whole set be CC0. Real
plasmid files are not redistributable — Addgene's terms are noncommercial-only
with an explicit anti-scraping clause, and lab files belong to their labs.

## Contents

176 cases, **163 of them hazard tier 1** — the class that is silent, expensive
and hard to notice at the bench.

| operation | cases | what it covers |
|---|---|---|
| `digest` | 123 | sites across the origin at every split point, isoschizomers, tandem and adjacent sites, explicit non-cutters, linear/circular contrast |
| `identity` | 42 | rotation invariance, strand invariance, palindromes, homopolymers, periodic and near-periodic sequences |
| `pcr` | 6 | amplification of an internal region with exact-match primers |
| `assembly` | 5 | two fragments sharing 30 bp terminal homology, circularised |

The origin cases are the point of the set. The same sequence appears twice —
once circular, once linear — and a tool must find the site in one and not the
other:

```
digest/origin-EcoRI-split3          circular, 306 bp   expect cut at 305
digest/origin-EcoRI-split3-linear   linear,   306 bp   expect no cuts
```

## Running it

```bash
python bench/run.py bench/polylinker-bench.json -- target/release/pl.exe bench-adapter
```

## Scoring another tool

Write an adapter. The contract is deliberately tiny:

```
<adapter> --capabilities
    one operation name per line — the ones it will attempt

<adapter>
    reads   id \t operation \t topology \t sequence [\t key=value]...
    writes  id \t key=value...       an answer
    or      id \t unsupported        declines this case
```

Anything a tool declines, or does not declare, is reported as UNSUPPORTED and
still counted in the denominator. A pass rate computed only over the cases a
tool chose to attempt is not a pass rate.

## Polylinker's score

Published because a benchmark whose author hides their own result is an
advertisement.

```
operation      pass   fail  unsup  total   rate
--------------------------------------------------------
assembly          0      0      5      5     0.0%
digest          123      0      0    123   100.0%
identity         42      0      0     42   100.0%
pcr               0      0      6      6     0.0%
--------------------------------------------------------
all             165      0     11    176    93.8%

hazard tier 1 (silent and expensive): 158 passed, 0 failed, 5 unsupported
```

Zero failures, and eleven cases Polylinker cannot attempt because it does not
implement PCR or assembly yet. That gap is real and the number says so.

## Regenerating

```bash
python bench/generate.py > bench/polylinker-bench.json
```

Deterministic — a fixed seed, so regenerating produces a byte-identical file
(SHA-256 `b331390965…`). Requires `biopython`, `seguid` and `pydna`.

## Conventions

- **Cut positions** — 1-based index of the base immediately 3′ of the nick on
  the top strand, as `Bio.Restriction` reports it.
- **Coordinates** — 1-based inclusive.
- **Checksums** — SEGUID v2 long form, prefix included.
