`show()` at :1128:

```js
state.digest = doc.length > 0 && doc.length <= 400000 ? coreDigest() : [];
```

Nothing downstream distinguishes "skipped" from "computed, found nothing." `renderEnzymes()` derives `const none = ENZYMES.filter(e => !state.digest.some(d => d.name === e[0]));` (:914) — for an empty digest, every enzyme — and prints it at :936 as a positive finding:


…followed by the full list of all 58 names. The paragraph directly above at :925 simultaneously claims "Computed live from a `${ENZYMES.length}`-enzyme textbook set, with circular wraparound handled." Nothing was computed. The summary strip at :883 prints "Unique cutters 0" from the same sentinel. The **only** disclosure lives at :1133 — `"enzyme scan skipped — sequence too large for this prototype"` — inside `mapHint`, the *Map* panel's header, and `@media (max-width:1000px)` at :145 stacks `.split`, so on a narrow window that line is off-screen above the Enzymes pane entirely. Where both are visible they contradict each other, and the more specific, enumerated claim is the false one.

**One-base cliff, measured.** Two generated GenBank files from the same generator:

```
b400000.gb  -> state.digest = 58 entries;  pane: "0 of the 58 enzymes ... do not cut"
b400001.gb  -> state.digest = 0;           pane: "58 of the 58 enzymes in the set do not
                                                  cut this molecule at all: AarI, AatII,
                                                  AflII, ... XmaI"
500000 bp   -> identical to b400001
```

Ground truth on the 500 kb file, `target/release/pl.exe digest`: **0 non-cutters, from 58 enzymes** (AarI 51 cuts, AatII 127, AflII 114 in my run; 71/134/119 in the finder's independent file). Every one of the 58 enzymes the page names as a non-cutter actually cuts.

*Reachability.* Not exotic. `README.md:94` calls the page "**Usable today**"; `docs/DNA-FORMAT.md:4` names a 4.64 Mb genome in the project's own validated corpus — 11× over the cap. Phage genomes, BACs and Plasmidsaurus long-read assemblies all clear 400 kb. The page's own comment at :1126-1127 says "The core scans a 4.6 Mb genome in well under a second, but this is the main thread; keep the interactive ceiling where it was" — the cap is a UI decision and the skip is expected in normal use. When null, replace the pane body — the "Computed live" paragraph, both section headers, the non-cutter note — with the reason: "Not computed — this molecule is N bp and this prototype caps the live scan at 400,000 bp." Print "—" rather than 0 for the summary strip's Unique cutters.

## Is there a round 4?

**No — not of this kind. This document recommends that sweeping stop.**

The argument is round 2's critic's, one ring outwards. That critic wrote of `crates/`:

> Four rounds, exhaustive fuzzing, 21 oracles, a byte-for-byte TypeScript diff and 210,721 cross-frontend assertions have yielded one LOW finding there. The Rust core is the best-verified part of this tree. Further sweeping it is theatre.

Round 3's yield says the same thing about everything else. Rounds 1+2: 87 raised, 33 survived, all fixed, including real moved coordinates. Round 3: 24 raised, 13 survived, 12 distinct, **zero wrong coordinates** — and **5 of those 12 came from the single file no round had ever opened**. The six units working over previously-swept ground produced 7, of which 4 are unfalsifiable checks inside test files and 3 are prose or gate labelling. **Yield tracks first contact with a surface, not effort spent on it.** There is no surface left that is both unopened and reachable by this method. The four blindness classes above are not effort problems.

The remaining work is maintainer work, in this order.

1. **Write the headless entry point.** Owed since round 2 (`docs/AUDIT-2026-08-13-r2.md:994`), unstarted — `git grep -i headless` over `bins/ tools/ docs/` returns a local variable in `recover.rs:764`, a line in `tools/readme/README-LINUX.txt`, and round 2's own request; `bins/pl-gui/src/main.rs:2906` is `app.open_argv(std::env::args_os().skip(1))`, file paths only, no verb. A `polylinker --headless <script>` that opens a document, runs a named sequence of app actions and dumps state as JSON converts **42% of the Rust** from read-only to both auditable and gate-able. Nothing else on this list unlocks as much.
2. **Fix the 12 survivors, `prototype/dna-reader.template.html` first** — F1 is the only user-facing false scientific statement found in three rounds. Then close R3-P3's second half: `tools/ci.ps1` mentions `prototype` **zero times in 4,019 lines**, and `prototype/check_page.js` prints ALL CHECKS PASSED against a four-commit-stale build. And decide F3 one way or the other: either the PDF gets its ground or the CHANGELOG stops saying it did.
3. **Settle the corpus, one way or the other.** Either license and commit a small real set, or — the honest cheap option, and what house rule 2 actually demands — restate every corpus-gated number in `README.md` as "measured once on a private corpus on \<date>; not reproducible from this repository." Three rounds have now written "buy a corpus" and it has not moved.
4. **Sign the 24 unsigned feature rows, and spot re-check a sample of the 89.** Human work, by name, under house rule 3. No agent may touch it and no agent has checked it. This is now the likeliest route from this tree to a wrong coordinate in a primer order.
5. **Run the gate once on Linux and once on macOS, keep the three ledgers, and run `tools/reconcile-ledgers.ps1` for real.** Cheap, and it closes blindness class 3 permanently.
6. **A differential fuzzer, if anything automated.** Not cargo-fuzz (needs cargo and nightly): a Python or node mutator over GenBank / `.dna` / ABIF, driving `pl.exe` and comparing against biopython. No round has done it; it is the only genuinely *new* automated method left.

**The one thing to put a human on rather than an agent:** `crates/pl-core/src/ed25519.rs` and `crates/pl-update/src/{flow.rs,net.rs,manifest.rs}` — half a day for someone who knows Ed25519. Not because it looks weak; it is the most defensively written code in the tree. Because its own header concedes the thing testing cannot settle: *"a signature verifier has to refuse things, and no vector file can enumerate everything it must refuse."* That is a specialist's judgment call, and the consequence of getting it wrong is not a wrong coordinate — it is a signed artifact on someone else's machine. It is a review, not a round.

**And the methodological note the next brief should carry rather than let be rediscovered a fourth time: `rustc` takes no `target/` lock, and `crates/` take zero external dependencies. Any module in this tree can be built and mutation-tested without cargo.** That is what turned this round from reading into measurement, and it should be the default.
